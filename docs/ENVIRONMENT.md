# Environment variables

Every variable the app reads. Required values stop startup with a message that names the variable and never prints its value. Optional values that are wrong produce a warning in the logs and fall back to the default, so a configuration detail cannot take the live site down.

`.env.example` holds the same list with placeholder values. Keep both files updated in every version.

## Required

| Name              | Purpose                                                                                                                              | Default | Example                                       |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------ | ------- | --------------------------------------------- |
| `DATABASE_URL`    | Postgres connection string.                                                                                                          | none    | `postgresql://USER:PASSWORD@HOST:5432/DBNAME` |
| `PUBLIC_SITE_URL` | Public address of the site. Used for canonical links, the social image and the sitemap. Only the origin is used.                     | none    | `https://www.example.com`                     |
| `ADMIN_PATH_SLUG` | Secret path of the admin entrance. 4 to 20 characters: letters, digits, underscore and hyphen. 12 or more recommended. Never logged. | none    | `k3x9Qm7vT2pLw8Zr4NbY`                        |

## Optional

| Name                        | Purpose                                                                                                                                                                          | Default       | Example      |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------- | ------------ |
| `NODE_ENV`                  | `production` turns on strict transport security and view caching.                                                                                                                | `development` | `production` |
| `PORT`                      | Port to listen on. Many hosts set this themselves.                                                                                                                               | `3000`        | `10000`      |
| `LOG_LEVEL`                 | `debug`, `info`, `warn` or `error`.                                                                                                                                              | `info`        | `info`       |
| `TRUSTED_PROXY_HOPS`        | Number of proxies in front of the app. Controls which address counts as the visitor's IP. Most platforms put one proxy in front (use 1). With 0, forwarding headers are ignored. | `0`           | `1`          |
| `RUN_MIGRATIONS`            | Apply pending migrations at startup.                                                                                                                                             | `true`        | `true`       |
| `DATABASE_SSL`              | `auto` uses TLS for any non-local host. `require` forces it. `disable` turns it off.                                                                                             | `auto`        | `auto`       |
| `DATABASE_SSL_STRICT`       | Verify the database server certificate. Leave off unless your host provides a certificate chain that Node trusts.                                                                | `false`       | `false`      |
| `DB_POOL_MAX`               | Maximum database connections in the pool.                                                                                                                                        | `10`          | `10`         |
| `DB_STATEMENT_TIMEOUT_MS`   | Query timeout in milliseconds.                                                                                                                                                   | `15000`       | `15000`      |
| `RATE_LIMIT_MAX`            | Requests allowed per visitor in each window.                                                                                                                                     | `300`         | `300`        |
| `RATE_LIMIT_WINDOW_SECONDS` | Length of the rate limit window.                                                                                                                                                 | `60`          | `60`         |
| `RATE_LIMIT_MAX_KEYS`       | Cap on tracked visitors, which bounds memory.                                                                                                                                    | `10000`       | `10000`      |
| `SHUTDOWN_TIMEOUT_MS`       | How long in-flight requests get to finish on shutdown.                                                                                                                           | `10000`       | `10000`      |

## Admin

The first two rows decide whether the admin area works at all. The rest have safe defaults.

| Name                           | Purpose                                                                                                                                                                                                                                                                                                                                                                             | Default              | Example           |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------- | ----------------- |
| `ADMIN_SECRET_KEY`             | Secret that all admin keys are derived from (encryption of authenticator secrets, form tokens, recovery code hashing). 43 to 256 characters of letters, digits, `-`, `_`, `+`, `/` or `=`, with some variety. If missing or malformed the admin area answers 503 and the public site is unaffected. Never logged. Changing it makes stored two-step secrets unreadable, so keep it. | none                 | a generated value |
| `ADMIN_INITIAL_EMAIL`          | Email of the first owner. Used only when no admin users exist, and for emergency recovery.                                                                                                                                                                                                                                                                                          | none                 | `you@example.com` |
| `ADMIN_INITIAL_PASSWORD`       | Password of the first owner. Must pass the password rules. The owner must change it at first sign-in. Remove it after first use. Never logged.                                                                                                                                                                                                                                      | none                 | a passphrase      |
| `ADMIN_REQUIRE_2FA`            | Two-step verification is mandatory for every admin user. Defaults to on in production and off elsewhere. A warning is logged if it is off in production.                                                                                                                                                                                                                            | `true` in production | `true`            |
| `ADMIN_LOGIN_MAX_FAILURES`     | Failed sign-ins per account and address in one window before throttling (3 to 50). Whole-account and whole-network limits are 4 times this.                                                                                                                                                                                                                                         | `5`                  | `5`               |
| `ADMIN_LOGIN_WINDOW_MINUTES`   | Length of the failure window (1 to 240).                                                                                                                                                                                                                                                                                                                                            | `15`                 | `15`              |
| `ADMIN_SESSION_IDLE_MINUTES`   | A session ends after this long without activity (5 to 1440).                                                                                                                                                                                                                                                                                                                        | `30`                 | `30`              |
| `ADMIN_SESSION_ABSOLUTE_HOURS` | A session ends this long after sign-in, however active (1 to 168).                                                                                                                                                                                                                                                                                                                  | `12`                 | `12`              |
| `ARGON2_MEMORY_KIB`            | Argon2id memory cost in KiB. The minimum accepted is 19456, the OWASP minimum.                                                                                                                                                                                                                                                                                                      | `19456`              | `19456`           |
| `ARGON2_TIME_COST`             | Argon2id iterations. Minimum 2.                                                                                                                                                                                                                                                                                                                                                     | `2`                  | `2`               |
| `ARGON2_PARALLELISM`           | Argon2id lanes.                                                                                                                                                                                                                                                                                                                                                                     | `1`                  | `1`               |
| `ADMIN_EMERGENCY_RESET`        | When `true`, at startup the owner whose email is `ADMIN_INITIAL_EMAIL` gets the password from `ADMIN_INITIAL_PASSWORD`, two-step verification is cleared and all their sessions end. Turn it off again afterwards. See `docs/ADMIN.md`.                                                                                                                                             | `false`              | `false`           |

Boolean values accept `true`, `false`, `1`, `0`, `yes` and `no`.

## Warnings you may see in the logs

- `ADMIN_PATH_SLUG is short`: values under 12 characters are accepted but easier to guess.
- `TRUSTED_PROXY_HOPS is 0 in production`: set it to the number of proxies in front of the app, otherwise every visitor shares one IP address for rate limiting.
- `PUBLIC_SITE_URL uses http in production`: canonical links should use https.
- `DATABASE_SSL is disable in production`: database traffic is not encrypted.
- `ADMIN_SECRET_KEY ...` (logged as an error): the secret is missing or malformed. The admin area is switched off until it is fixed.
- `ADMIN_REQUIRE_2FA is false in production`: two-step verification should be mandatory for admin users.
- `ADMIN_EMERGENCY_RESET is true`: the owner password is replaced on every start while this stays on. Turn it off after you have signed in.
- `ADMIN_INITIAL_PASSWORD was rejected`: the first owner was not created because the password breaks the rules (too short, too common, contains the email).
